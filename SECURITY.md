# Security policy

Supported baseline: **Godot 4.7**, verified in CI with **4.7.2-stable**.

For sensitive security reports, use the repository's **GitHub Security > Report a vulnerability** private reporting option when enabled, or contact maintainers privately. Do not publish exploitation details in a public issue.

The starter intentionally performs **no network requests, installs no dependencies, and does not change the consuming project's settings**. Review third-party code before adding it.
